# Provenance and scope

Snapshot date: 2026-08-24.

Public project repository: https://github.com/jterning/jnr-higgs-zero-certificates

This submission snapshot freezes the exact-rational-envelope verifier corresponding to the formulas printed in Appendix I of the manuscript. It is self-contained and does not read a stored subdivision tree or a precomputed Bernstein coefficient table. The two JSON files are outputs generated by the included verifier logic in the pinned reference environment.

The archive certifies only the two finite-tilt empty-region statements used to make the analytic near-aligned stability theorem effective. It is not used for the exact aligned nodal bound or for the existence of a nonzero near-aligned neighborhood.
